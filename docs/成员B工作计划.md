## Step 1：搭建后端框架，定义接口格式（优先完成，第 1 天）

**做什么：**
- 在 `backend/` 目录下创建以下文件结构：
  ```
  backend/
  ├── app.py          # Flask 主入口，注册路由
  ├── recognition.py  # 识别逻辑
  ├── knowledge.py    # 读取 patterns.json 和 artifacts.json
  ├── generator.py    # 生成 AI 讲解文本
  ├── config.py       # 路径配置（data 目录、uploads 目录）
  ├── requirements.txt
  └── uploads/        # 上传图片临时目录
  ```
- 在 `app.py` 中注册所有接口路由（可以先返回空 JSON 占位）：
  - `POST /api/recognize`
  - `GET /api/patterns`
  - `GET /api/patterns/<pattern_id>`
  - `GET /api/artifacts`
  - `GET /api/health`
- **把接口返回格式发给成员 A**，让 A 可以开始写前端的 API 调用代码，不要互相等待。

**产出：** backend 目录结构建立，接口路由可访问（哪怕暂时返回空数据），接口格式文档告知 A。

## Step 2：实现知识库和案例库读取接口（第 1–2 天）

**做什么：**
- 在 `knowledge.py` 中写两个函数：
  - `get_all_patterns()`：读取 `data/patterns.json`，返回全部纹样
  - `get_artifacts_by_pattern(pattern_id)`：读取 `data/artifacts.json`，按纹样类别筛选案例

  - `GET /api/patterns` → 返回全部纹样知识

## Step 3：实现核心识别接口 `/api/recognize`（第 2–4 天）

这是整个后端最重要的接口，分两层实现：

**第一层：示例图片映射（优先实现，保证演示稳定）**
- 接收上传图片，保存到 `uploads/`
- 从文件名中判断是否命中 `demo_images.json` 的映射
- 如果命中，直接返回预设的 `pattern_id` 和 `confidence`
- 这一层保证视频录制时结果 100% 稳定

**第二层：基础相似度匹配（备用，非关键路径）**
- 如果图片不是示例图片，使用 pHash（感知哈希）与样本库图片做相似度计算
- 返回最相似的纹样类别，并附加"仅供学习参考"的提示

**组装完整返回 JSON：**
```json
{
  "success": true,
  "pattern_id": "dragon",
  "pattern_name": "龙纹",
  "confidence": 0.86,
  "visual_reason": "...",
  "knowledge": { ... },
  "similar_artifacts": [ ... ],
  "ai_explanation": "..."
}
```

**数据来源：** C 已完成 `demo_images.json` 和示例图片，直接使用。

**产出：** 上传示例图片后能返回完整识别结果 JSON。
